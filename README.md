# 업비트 ↔ 빗썸 현물 차익 모니터 & 매매일지

트레이딩 데스크(LP·차익거래) 업무 방식을 소액 크립토 현물 차익으로 실습하는 프로젝트.

## 구성
| 파일 | 역할 |
|---|---|
| `arb_monitor.py` | 양 거래소 호가 수집 → 호가 깊이·수수료 반영 순괴리(bp) 계산 → CSV 기록 (주문 기능 없음) |
| `analyze_log.py` | 로그 분석: 코인·방향별 기회 빈도, 시간대별 패턴, 호가 깊이 슬리피지 |
| `크립토차익_매매일지.xlsx` | 운용규칙 / 매매일지 / 재고 / 일일 PnL 분해 / 주간회고 |

## 설계 포인트
- **재고 모델**: 양 거래소에 원화·코인을 미리 배치하고 동시 매수·매도 (송금 리스크 제거, ETF LP 재고 운영과 동일한 구조)
- **VWAP 기반 엣지**: 최우선호가가 아니라 설정 금액이 실제 체결될 평균가로 계산
- **손익 분해**: 스프레드 수익 − 수수료 − 리밸런싱비용 = 차익손익 / 재고평가손익은 별도 분리
- **기대 vs 실현**: 모니터 순괴리와 실제 체결 순괴리의 차이를 실행 슬리피지로 측정

## 실행
```
pip install requests pandas
python arb_monitor.py --mock --once   # 동작 확인
python arb_monitor.py                 # 실시간 모니터링
python analyze_log.py                 # 로그 분석
```
